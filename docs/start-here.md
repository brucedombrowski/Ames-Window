# Start here: the compliance side of this repository

`tour.md` is the reading order for the code. This is the reading order for
everything else. Each item is one short document; the whole set takes about
an hour.

Ames Window is a trivial application kept trivial on purpose, so that the
process around it can be shown in full. The process follows the
[systems-engineering](https://github.com/brucedombrowski/systems-engineering)
framework and cites only openly published standards.

## Read in this order

1. **[`standards.md`](standards.md)**: which standards bind this project, which
   do not and why, and the rule that only freely available texts are normative.
2. **[`configuration-management.md`](configuration-management.md)**: the plan.
   What is controlled, the three change classes and who decides each, the five
   process steps, what tools enforce versus what people own, what records exist.
3. **[`REQ-2026-001.json`](REQ-2026-001.json)**: the requirements. Outcome
   requirements first, in the form an acquirer writes them, then the mechanisms
   that satisfy each, every one citing a standard and section.
4. **[`VER-2026-001.md`](VER-2026-001.md)**: the evidence. Every requirement
   traced to a file and line, or marked open with its tracking issue. Generated;
   CI fails if it drifts from the code.
5. **[`RISK-2026-001.md`](RISK-2026-001.md)**: the risk register. What could go
   wrong, how likely, how bad, what reduces it, what is left and who owns that.
6. **`DM-2026-*.md`**: the decision memoranda, one per choice an assessor
   might question. Options considered, decision, rationale with references.
7. **[`facts.json`](facts.json)**: the numbers. Every count quoted in a document
   or briefing comes from here, never from memory.
8. **[`../CHANGELOG.md`](../CHANGELOG.md)** and **[`../deployments.toml`](../deployments.toml)**:
   what changed, and what has been delivered to and installed where.

## Three events to keep apart

A **release** is a tagged version with its assets. A **delivery** hands a
release to a recipient, with an SVD cut from that recipient's baseline. An
**installation** is the recipient putting it into use. Each has its own
record. See the CM plan and issue #10.

## One rule above the rest

The application never has network capability. It is not a change class; it is
the charter. See `DM-2026-001.md` and issue #8.
